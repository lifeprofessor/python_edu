📖 모듈과 패키지 배우기

🤔 모듈이란 무엇일까요?

모듈은 다른 파일의 코드를 가져와서 사용하는 기능입니다. 마치 친구가 만든 레시피를 빌려와서 요리하는 것처럼, 다른 사람이 만든 코드를 가져와서 사용할 수 있습니다.

🏠 실생활 비유
  • • 도서관: 필요한 책을 빌려와서 사용
  • • 공구함: 필요한 도구를 꺼내서 사용
  • • 부품상자: 필요한 부품을 찾아서 조립

🤖 MechDog 모듈 구조

실제 MechDog 코드에서는 이런 모듈들을 사용합니다:

📝 기본 모듈들
import Hiwonder      # 로봇 제어
import time          # 시간 관리
from HW_MechDog import MechDog  # 로봇 클래스
🎯 센서 모듈들
import Hiwonder_IIC  # I2C 통신
from HW_MechDog import MechDog
import math          # 수학 계산

📥 import 방법들

모듈을 가져오는 방법은 여러 가지가 있습니다:

📝 전체 가져오기
import math
result = math.sqrt(16)
🎯 부분 가져오기
from math import sqrt
result = sqrt(16)
🏷️ 별명 사용하기
import math as m
result = m.sqrt(16)

🔧 change_body_height-detail.py

import Hiwonder  # 로봇 조종 도구
import time      # 시간 지연 기능
from HW_MechDog import MechDog  # MechDog 클래스

mechdog = MechDog()  # 로봇 객체 생성

# 몸체 높이 변경 함수
mechdog.transform([0, 0, 20], [0, 0, 0], 1000)
# [x, y, z] 위치, [roll, pitch, yaw] 각도, 시간(ms)

📡 ultrasonic_ranging-detail.py

import Hiwonder_IIC  # I2C 통신 모듈
from HW_MechDog import MechDog

# I2C 초음파 센서 설정
i2c1 = Hiwonder_IIC.IIC(1)
i2csonar = Hiwonder_IIC.I2CSonar(i2c1)

# 거리 측정 및 LED 제어
distance = i2csonar.getDistance()
if distance < 15:
    i2csonar.setRGB(0, 0xff, 0x00, 0x00)  # 빨강
