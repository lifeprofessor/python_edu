📖 모듈과 패키지 배우기

🤔 모듈이란 무엇일까요?

모듈은 다른 파일의 코드를 가져와서 사용하는 기능입니다. 마치 친구가 만든 레시피를 빌려와서 요리하는 것처럼, 다른 사람이 만든 코드를 가져와서 사용할 수 있습니다.

🏠 실생활 비유
  • • 도서관: 필요한 책을 빌려와서 사용
  • • 공구함: 필요한 도구를 꺼내서 사용
  • • 부품상자: 필요한 부품을 찾아서 조립

🤖 MechDog 모듈 구조

실제 MechDog 코드에서는 이런 모듈들을 사용합니다:

📝 기본 모듈들
import Hiwonder      # 로봇 제어
import time          # 시간 관리
from HW_MechDog import MechDog  # 로봇 클래스
🎯 센서 모듈들
import Hiwonder_IIC  # I2C 통신
from HW_MechDog import MechDog
import math          # 수학 계산

📥 import 방법들

모듈을 가져오는 방법은 여러 가지가 있습니다:

📝 전체 가져오기
import math
result = math.sqrt(16)
🎯 부분 가져오기
from math import sqrt
result = sqrt(16)
🏷️ 별명 사용하기
import math as m
result = m.sqrt(16)

import random import statistics import math from datetime import datetime, timedelta def comprehensive_system(): """MechDog 종합 관리 시스템""" print("🤖 MechDog 종합 관리 시스템 v1.0") print("=" * 40) # 1. 시스템 시작 시간 기록 start_time = datetime.now() print(f"🕐 시스템 시작: {start_time.strftime('%Y-%m-%d %H:%M:%S')}") # 2. 센서 데이터 시뮬레이션 및 분석 print("📊 센서 데이터 분석") sensor_data = [random.randint(10, 50) for _ in range(10)] print(f"📡 수집된 데이터: {sensor_data}") print(f"📈 평균값: {statistics.mean(sensor_data):.1f}") print(f"📊 중간값: {statistics.median(sensor_data)}") # 3. 오늘의 임무 스케줄 생성 print("📅 오늘의 임무 스케줄") missions = ["순찰", "점검", "청소", "대기"] for i, mission in enumerate(missions): mission_time = start_time + timedelta(hours=i+1) print(f" {mission_time.strftime('%H:%M')} - {mission}") # 4. 랜덤 순찰 경로 생성 print("🗺️ 순찰 경로") zones = ["현관", "거실", "주방", "안뜰"] random.shuffle(zones) for i, zone in enumerate(zones): print(f" {i+1}. {zone}") # 5. 경로 거리 계산 (가상 좌표) coordinates = [(0, 0), (5, 3), (8, 7), (2, 9)] total_distance = 0 print("📏 이동 거리 계산") for i in range(len(coordinates)-1): x1, y1 = coordinates[i] x2, y2 = coordinates[i+1] distance = math.sqrt((x2-x1)**2 + (y2-y1)**2) total_distance += distance print(f" 구간 {i+1}: {distance:.2f}m") print(f"🚀 총 거리: {total_distance:.2f}m") # 6. 시스템 상태 리포트 print("📋 시스템 상태") battery = random.randint(60, 100) temperature = random.randint(20, 30) print(f"🔋 배터리: {battery}%") print(f"🌡️ 온도: {temperature}°C") if battery > 80: status = "🟢 최적" elif battery > 50: status = "🟡 양호" else: status = "🔴 주의" print(f"⚡ 시스템 상태: {status}") print("✅ 시스템 초기화 완료!") # 시스템 실행 comprehensive_system()
