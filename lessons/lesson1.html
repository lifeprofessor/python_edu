📖 이론 학습

🔤 print() 함수란?

print() 함수는 파이썬에서 가장 기본적인 함수입니다. 화면에 문자나 숫자를 출력할 때 사용합니다.

기본 문법:
print("출력하고 싶은 내용")

📝 문자열과 따옴표

문자열은 글자들의 조합입니다. 파이썬에서는 따옴표(" " 또는 ' ')로 문자열을 표현합니다.

✅ 올바른 예:
print("Hello, World!")
print('안녕하세요')
print("MechDog 안녕!")
❌ 잘못된 예:
print(Hello, World!)
print("안녕하세요')
print(MechDog 안녕!)

🚀 print() 함수의 다양한 사용법

print() 함수는 단순히 글자를 출력하는 것 외에도 다양한 방법으로 활용할 수 있습니다!

번호 방법 코드 예시 설명
1 기본 출력 print("안녕하세요") 글자를 화면에 그대로 보여줘요
2 여러 개 출력 print("안녕", "나는", "파이썬이야") 쉼표로 나누면 자동으로 띄어쓰기 돼요
3 줄 바꾸지 않기 print("Hello", end=" ")
print("World") 		end를 이용해서 줄바꿈 없이 이어서 출력해요
4 구분자 바꾸기 print("2025", "06", "09", sep="-") sep로 글자 사이에 넣을 기호를 정할 수 있어요
5 변수 넣기 (f-string) name = "지민"
print(f"안녕 {name}") 		f"문장{변수}"처럼 변수 값을 문장에 넣을 수 있어요
💡 실제 실행 결과 예시:
📝 코드:
print("안녕", "나는", "MechDog")
print("2025", "06", "09", sep="-")
print("Hello", end=" ")
print("World!")
name = "파이썬"
print(f"안녕하세요 {name}입니다")

📝 정리

✅ 이번 레슨에서 배운 내용

  • • 기본 출력: print("내용") - 화면에 내용을 출력
  • • 여러 개 출력: print("A", "B", "C") - 쉼표로 구분하여 한번에 출력
  • • 줄바꿈 제어: print("내용", end=" ") - end로 줄바꿈 방식 조정
  • • 구분자 설정: print("A", "B", sep="-") - sep로 값 사이 구분자 지정
  • • 변수 활용: f"안녕 {name}" - f-string으로 변수 값을 문장에 삽입
  • • 문자열: 따옴표(" " 또는 ' ')로 감싸서 표현
  • • 첫 번째 코드: "Hello, World!" 출력 성공
  • • MechDog 연결: 로봇 제어의 첫 걸음
