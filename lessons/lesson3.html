조건문 (if-else)

MechDog이 상황에 따라 다른 행동을 하도록 만들기

🎯 학습 목표

  • • if, elif, else 문의 사용법 이해하기
  • • 비교 연산자로 조건 만들기
  • • MechDog의 상태에 따른 다른 행동 구현하기
  • • 논리 연산자 활용하기

📖 조건문 배우기

🔍 기본 문법

if 조건:
    실행할 코드
elif 다른조건:
    다른 코드
else:
    기본 코드

⚖️ 비교 연산자

== 같다
!= 다르다
> 크다
< 작다
>= 크거나 같다
<= 작거나 같다

  2. 2. 3번 틀리면 잠금 모드
  3. 3. 올바른 비밀번호시 환영 메시지

📝 정리

✅ 핵심 내용

  • • if문: 조건이 참일 때 실행
  • • elif문: 다른 조건 추가
  • • else문: 모든 조건이 거짓일 때
  • • 비교 연산자: ==, !=, >, <, >=, <=
