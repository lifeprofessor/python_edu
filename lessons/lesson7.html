📖 클래스와 객체 배우기

🤔 클래스란 무엇일까요?

클래스는 객체를 만들기 위한 설계도입니다. 마치 로봇 제작을 위한 도면처럼, MechDog의 특성과 행동을 체계적으로 정의할 수 있습니다.

🏠 실생활 비유
  • • 설계도: 집을 짓기 위한 도면
  • • 붕어빵 틀: 붕어빵을 만드는 틀
  • • 쿠키 커터: 쿠키 모양을 만드는 틀
  • • 로봇 설계서: MechDog를 만들기 위한 명세서

🤖 객체란 무엇일까요?

객체는 클래스를 바탕으로 실제로 만들어진 실체입니다. 하나의 MechDog 클래스로 여러 개의 MechDog 객체를 만들 수 있습니다.

📝 클래스 vs 객체
  • • 클래스: MechDog 설계도 (1개)
  • • 객체: 실제 MechDog들 (여러 개)
  • • 속성: 이름, 배터리, 위치
  • • 메서드: 움직이기, 짖기, 앉기
🐕 MechDog 예시
class MechDog:           # 클래스 (설계도)
    def __init__(self, name):
        self.name = name     # 속성

buddy = MechDog("Buddy")     # 객체 (실체)
max = MechDog("Max")         # 또 다른 객체

📝 MechDog 클래스 구조

실제 MechDog는 이런 구조로 설계됩니다:

class MechDog:
    """MechDog 클래스 - 로봇강아지의 설계도"""
    
    def __init__(self, name):
        """생성자 - MechDog 초기화"""
        self.name = name         # 속성: 이름
        self.battery = 100       # 속성: 배터리
        self.status = "대기"     # 속성: 상태
        print(f"🤖 {self.name} MechDog 생성됨!")
    
    def bark(self):
        """메서드: 짖기 기능"""
        if self.battery > 5:
            print(f"{self.name}: 멍멍! 🐕")
            self.battery -= 5
        else:
            print(f"{self.name}: 배터리 부족... 😴")
    
    def move(self, direction):
        """메서드: 이동 기능"""
        if self.battery > 10:
            print(f"{self.name}이 {direction}으로 이동합니다! 🚶")
            self.battery -= 10
        else:
            print(f"{self.name}: 배터리 부족으로 이동 불가 ❌")

# 객체 생성과 사용
buddy = MechDog("Buddy")    # 첫 번째 MechDog 객체
max_dog = MechDog("Max")    # 두 번째 MechDog 객체

🔧 속성과 메서드 심화

🎯 MechDog의 속성과 메서드

클래스의 속성(변수)과 메서드(함수)를 통해 MechDog의 상태와 행동을 정의합니다.

📊 MechDog 속성들
  • • self.name: MechDog의 이름
  • • self.battery: 배터리 잔량 (0-100)
  • • self.status: 현재 상태 (대기/이동/짖기)
  • • self.position: 현재 위치 좌표
🎭 MechDog 메서드들
  • • __init__(): 초기화/생성자
  • • bark(): 짖기 동작
  • • move(): 이동 동작
  • • sit(): 앉기 동작

📝 정리

✅ 핵심 내용

  • • 클래스(Class): 객체를 만들기 위한 설계도
  • • 객체(Object): 클래스를 바탕으로 만든 실체
  • • 속성(Attribute): 객체의 특성 (변수)
  • • 메서드(Method): 객체의 행동 (함수)
  • • 생성자(__init__): 객체 초기화 메서드
  • • 특수 메서드: __str__, __eq__ 등으로 기능 확장
