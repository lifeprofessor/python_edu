📖 이론 학습

📦 변수란?

변수는 데이터를 저장하는 상자와 같습니다. MechDog의 이름, 위치, 배터리 등의 정보를 저장할 수 있어요.

변수 만들기:
변수이름 = 값
✅ 좋은 변수명:
dog_name = "멍멍이"
battery_level = 85
is_moving = True
❌ 피해야 할 변수명:
1dog = "멍멍이" (숫자로 시작)
dog-name = "멍멍이" (하이픈 사용)
print = "출력" (예약어 사용)

🏷️ 데이터 타입

파이썬에는 여러 종류의 데이터 타입이 있습니다. MechDog 제어에 필요한 주요 타입들을 알아보세요.

📝 문자열 (str)
"MechDog"
'로보독'
"안녕하세요"
🔢 정수 (int)
100 (배터리)
4 (다리 개수)
-5 (음수도 가능)
💯 실수 (float)
23.5 (온도)
1.2 (속도)
0.5 (확률)
✅ 불린 (bool)
True (켜짐)
False (꺼짐)
참/거짓만 가능

🔗 f-string 문자열 포맷팅

f-string을 사용하면 변수를 문자열 안에 쉽게 넣을 수 있습니다.

사용법:
f"문자열 {변수명} 더 많은 문자열"

문제 1: 변수 선언

다음 중 올바른 변수 선언은?

2dog = "멍멍이"

문제 2: 데이터 타입

변수 battery = 85의 데이터 타입은?

str (문자열)
int (정수)
float (실수)
bool (불린)

문제 3: f-string

name = "MechDog"일 때, print(f"안녕, {name}!")의 출력 결과는?

안녕, MechDog!
안녕, {name}!
f"안녕, {name}!"
안녕, name!

📝 정리

✅ 이번 레슨에서 배운 내용

  • • 변수: 데이터를 저장하는 상자, 변수명 = 값
  • • 문자열(str): 따옴표로 감싼 글자들
  • • 정수(int): 소수점이 없는 숫자
  • • 실수(float): 소수점이 있는 숫자
  • • 불린(bool): True 또는 False
  • • f-string: f"문자열 {변수} 문자열"
