🔄 레슨 4: 반복문으로 동작 반복

MechDog이 같은 동작을 여러 번 실행하도록 해보세요!

🔁 for 반복문

for 반복문은 정해진 횟수만큼 코드를 반복 실행합니다.

📝 for 반복문 기본 구조

for 변수 in range(횟수):
    실행할 코드
여기에 실행 결과가 표시됩니다

🔄 while 반복문

while 반복문은 조건이 참인 동안 계속 반복합니다.

📝 while 반복문 기본 구조

while 조건:
    실행할 코드
    조건 변경
여기에 실행 결과가 표시됩니다

📊 리스트 기초

리스트는 여러 개의 값을 순서대로 저장하는 데이터 구조입니다.

📝 리스트 기본 구조

리스트명 = [값1, 값2, 값3, ...]
리스트명[인덱스]  # 특정 위치의 값 가져오기
여기에 실행 결과가 표시됩니다

🔄 리스트와 반복문

리스트의 모든 요소를 반복문으로 하나씩 처리할 수 있습니다.

💡 리스트 반복문 방법

  • for 요소 in 리스트: 각 요소에 직접 접근
  • for i in range(len(리스트)): 인덱스로 접근
  • for i, 요소 in enumerate(리스트): 인덱스와 요소 모두 사용
여기에 실행 결과가 표시됩니다

🛑 반복문 제어

break와 continue로 반복문을 제어할 수 있습니다.

💡 반복문 제어 키워드

  • break: 반복문을 완전히 종료
  • continue: 현재 반복을 건너뛰고 다음 반복으로
여기에 실행 결과가 표시됩니다
