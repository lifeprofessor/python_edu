반복문 (for, while)

MechDog이 같은 동작을 여러 번 반복하도록 만들기

🎯 학습 목표

  • • for 반복문으로 정해진 횟수만큼 반복하기
  • • while 반복문으로 조건이 참인 동안 반복하기
  • • 리스트와 반복문을 함께 사용하기
  • • break와 continue로 반복문 제어하기

📖 반복문 배우기

🔄 for 반복문

정해진 횟수만큼 또는 리스트의 모든 요소에 대해 반복 실행합니다.

📊 정해진 횟수만큼 반복
for i in range(3):
    print(f"{i+1}번째 동작")
    # 실행 결과:
    # 1번째 동작
    # 2번째 동작
    # 3번째 동작
📋 리스트 요소 반복
actions = ["앉기", "서기", "돌기"]
for action in actions:
    print(f"MechDog {action}")
    # 실행 결과:
    # MechDog 앉기
    # MechDog 서기
    # MechDog 돌기
💡 핵심 포인트
  • • range(숫자): 0부터 (숫자-1)까지 반복
  • • range(시작, 끝): 시작부터 (끝-1)까지 반복
  • • 리스트의 각 요소를 순서대로 처리
  • • 들여쓰기로 반복할 코드 블록 구분

⏰ while 반복문

조건이 참인 동안 계속해서 반복 실행합니다.

🔋 조건 기반 반복
battery = 100
while battery > 20:
    print(f"배터리: {battery}%")
    battery -= 10
print("충전 필요!")
# 실행 결과:
# 배터리: 100%
# 배터리: 90%
# 배터리: 80%
# ...
# 배터리: 30%
# 배터리: 20%
# 충전 필요!
🔄 무한 반복 + break
count = 0
while True:
    count += 1
    if count > 5:
        break
    print(f"{count}번째 실행")
# 실행 결과:
# 1번째 실행
# 2번째 실행
# 3번째 실행
# 4번째 실행
# 5번째 실행
💡 핵심 포인트
  • • 조건이 True인 동안 계속 반복
  • • 반드시 조건을 변경하는 코드가 필요
  • • break로 강제 종료 가능
  • • 무한 반복 주의! (조건이 절대 False가 되지 않으면)

🛑 반복문 제어하기

반복문의 실행을 세밀하게 제어할 수 있습니다.

⏹️ break - 반복문 종료
for i in range(10):
    if i == 5:
        break
    print(i)
# 실행 결과:
# 0
# 1
# 2
# 3
# 4
⏭️ continue - 건너뛰기
for i in range(5):
    if i == 2:
        continue
    print(i)
# 실행 결과:
# 0
# 1
# 3
# 4
💡 제어 명령어
  • • break: 반복문을 완전히 종료
  • • continue: 현재 반복을 건너뛰고 다음으로
  • • 중첩 반복문에서 가장 가까운 반복문에만 적용

🏠 실생활 예제

반복문이 실제로 어떻게 사용되는지 알아봅시다.

🎮 게임 루프
# 게임이 끝날 때까지 계속 실행
while game_running:
    get_user_input()
    update_game_state()
    draw_screen()
    if player_died:
        game_running = False
📱 메뉴 시스템
# 메뉴 옵션들을 순서대로 처리
menu_options = ["시작", "설정", "도움말", "종료"]
for option in menu_options:
    print(f"- {option}")
    # 각 메뉴 항목을 화면에 표시
🔍 데이터 검색
# 리스트에서 특정 값 찾기
numbers = [1, 3, 5, 7, 9, 11]
for num in numbers:
    if num == 7:
        print("7을 찾았습니다!")
        break
