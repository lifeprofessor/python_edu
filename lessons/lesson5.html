📖 함수 배우기

🤔 함수란 무엇일까요?

함수는 특정 작업을 수행하는 코드의 모음입니다. 마치 요리 레시피처럼, 재료(입력)를 넣으면 완성된 요리(결과)가 나오는 것과 같습니다.

🍳 실생활 비유
  • • 자판기: 돈을 넣으면 음료수가 나옴 (입력 → 처리 → 출력)
  • • 계산기: 숫자를 입력하면 계산 결과가 나옴
  • • 요리 레시피: 재료를 넣으면 완성된 요리가 나옴

🔧 함수의 기본 구조

함수는 def로 시작하고, 들여쓰기로 함수 내용을 구분합니다.

📝 기본 문법
def 함수이름():
    실행할 코드
    return 반환값  # 선택사항

# 함수 호출
함수이름()
🎯 간단한 예제
def 인사하기():
    print("안녕하세요!")
    print("반갑습니다!")

# 함수 사용하기
인사하기()

📥 매개변수 (Parameter)

매개변수는 함수에 전달하는 값입니다. 마치 자판기에 동전을 넣는 것처럼, 함수에 필요한 정보를 전달할 수 있습니다.

📝 매개변수 문법
def 함수이름(매개변수):
    매개변수를 사용한 코드

# 함수 호출
함수이름(인수)
🎯 쉬운 예제
def 인사하기(이름):
    print(f"안녕하세요, {이름}님!")
    print("반갑습니다!")

# 함수 사용하기
인사하기("철수")
인사하기("영희")

📤 반환값 (Return Value)

반환값은 함수가 작업을 완료한 후 돌려주는 결과입니다. 계산기의 결과값처럼, 함수의 실행 결과를 받아올 수 있습니다.

📝 반환값 문법
def 함수이름():
    계산 과정
    return 결과값

# 결과 받기
결과 = 함수이름()
🎯 쉬운 예제
def 더하기(a, b):
    결과 = a + b
    return 결과

# 결과 받기
합계 = 더하기(5, 3)
print(f"5 + 3 = {합계}")

⚙️ 기본값 (Default Value)

기본값은 매개변수에 값을 전달하지 않았을 때 사용되는 기본 설정값입니다. 마치 자판기의 기본 음료수처럼, 아무것도 선택하지 않으면 기본값이 나옵니다.

📝 기본값 문법
def 함수이름(매개변수=기본값):
    실행할 코드

# 다양한 방법으로 호출
함수이름()  # 기본값 사용
함수이름(새값)  # 새 값 사용
🎯 쉬운 예제
def 인사하기(이름="친구"):
    """이름을 받아서 인사하는 함수 (기본값: 친구)"""
    print(f"🐕 안녕하세요, {이름}님!")
    print("반갑습니다!")

# 다양한 방법으로 호출
인사하기()  # "안녕하세요, 친구님!"
인사하기("철수")  # "안녕하세요, 철수님!"
