⚙️ 레슨 5: 함수로 코드 정리하기

반복되는 MechDog 동작을 함수로 만들어 코드를 깔끔하게 정리해보세요!

🔧 함수 기본

함수는 특정 작업을 수행하는 코드 블록입니다. 반복되는 코드를 줄이고 프로그램을 체계적으로 만들 수 있습니다.

📝 함수 정의하기

def 함수이름():
    실행할 코드
    return 반환값  # 선택사항
여기에 실행 결과가 표시됩니다

📥 매개변수가 있는 함수

함수에 매개변수를 전달하여 더 유연한 동작을 만들 수 있습니다.

📝 매개변수와 인수

def 함수이름(매개변수):
    매개변수를 사용한 코드

함수이름(인수)  # 함수 호출
여기에 실행 결과가 표시됩니다

📤 반환값이 있는 함수

return을 사용하여 함수에서 값을 돌려받을 수 있습니다.

여기에 실행 결과가 표시됩니다

⚙️ 기본값과 키워드 인수

함수의 매개변수에 기본값을 설정하고, 키워드로 인수를 전달할 수 있습니다.

💡 함수 고급 기능

  • 기본값: 매개변수에 기본값 설정
  • 키워드 인수: 매개변수 이름으로 값 전달
여기에 실행 결과가 표시됩니다

🎯 실습 과제

함수를 사용해서 MechDog의 복합 동작을 구현해보세요!

🎪 MechDog 시스템 구축

다음 함수들을 만들어보세요:

  • greet_visitor(name): 방문자에게 인사하기
  • patrol_area(rounds=3): 지역 순찰하기
  • emergency_response(danger_level): 위험도에 따른 대응
  • daily_report(): 하루 활동 보고서
여기에 실행 결과가 표시됩니다

💡 해답 예시

def greet_visitor(name):
    print(f"🤖 안녕하세요 {name}님!")
    print("🐕 멍멍! 환영합니다!")

def patrol_area(rounds=3):
    print(f"🛡️ {rounds}회 순찰을 시작합니다.")
    for i in range(rounds):
        print(f"  {i+1}차 순찰 중... 이상무!")
    print("✅ 순찰 완료!")

def emergency_response(danger_level):
    if danger_level == 1:
        print("🟡 경계 모드 - 센서 활성화")
    elif danger_level == 2:
        print("🟠 주의 모드 - 경보음 발생")
    else:
        print("🔴 위험 모드 - 즉시 신고!")

def daily_report():
    print("📊 오늘의 활동 보고:")
    print("- 순찰: 완료")
    print("- 방문자 응대: 3명")
    print("- 이상 상황: 없음")
