🤖 MechDog 소개

특별 강의

MechDog은 파이썬으로 제어할 수 있는 로봇 개입니다. 기본적인 파이썬 문법을 배우고 나면 실제로 MechDog을 움직이고, 명령을 내리고, 센서 데이터를 읽을 수 있어요!

🎯 MechDog으로 할 수 있는 것들

  • ✓앞뒤좌우 이동
  • ✓고개 돌리기
  • ✓앉기/일어서기
  • ✓손 흔들기
  • ✓LED 색상 변경
  • ✓음성 출력
  • ✓센서 데이터 읽기

📚 필요한 파이썬 지식

  • •변수와 데이터 타입
  • •함수 정의와 호출
  • •조건문 (if-else)
  • •반복문 (for, while)
  • •클래스와 객체
  • •모듈 import
  • •파일 입출력
